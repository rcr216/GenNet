How it works

How GenNet works

A federated network for rare-disease genomic intelligence. Each hospital keeps its patient records. Only aggregate counts travel — never the patient.

1

Hospitals join the network

A doctor requests to join. The admin approves. The hospital appears on the map and the doctor gets a private space.

2

Each hospital adds patients privately

Full patient records — variant, phenotype, drug response, clinical notes — stay inside the hospital's own simulator. Like the real system: each hospital's data lives on its own server.

3

Only the aggregate travels

When a patient is registered, a Beacon-style aggregate is sent to the coordinator — variant, effect, exon, phenotype, drug response. No patient identity. No demographics. No clinical notes.

4

Coincidences emerge across the network

The coordinator finds matches in 6 levels: exact variant · same codon · same exon · same protein domain · same effect type · same phenotype. Doctors see which hospitals share a finding, never which patients.
